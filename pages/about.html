About StudyFlow

A clean, distraction-free student productivity system. Organize subjects, manage tasks with categories and time estimates, run Pomodoro focus sessions, capture notes, and track your momentum — with complete privacy.

Everything you need to excel

Dynamic Dashboard

Today's priorities, upcoming 7-day deadlines, exam countdowns, subject progress, and recent activity.

Enhanced Task System

Task categories (Assignments, Reading, Revision), time estimates, priorities, overdue highlights, and instant filtering.

Interactive Calendar

Month overview with exam badges, task completion states, and interactive day detail popup with inline toggles.

Focus & Pomodoro Timer

Focus (25m), Short Break (5m), Long Break (15m), Web Audio chimes, and automatic session logging linked to subjects.

Analytics & Activity Log

Subject-by-subject completion ratios, priority breakdowns, focus streak tracking, and chronological activity feed.

Notes & Knowledge

Rich study notes with markdown support, pin favorites, link directly to subjects, and rapid search filtering.

Settings & Data Control

Safe pre-import validation, visual side-by-side JSON preview, storage diagnostics, focus targets, and theme preferences.

Global Search (Cmd+K)

Instant unified search across all tasks, subjects, and notes with keyboard navigation support.

Built with Pure Web Standards

Fast, lightweight, zero build steps, and zero external runtime dependencies.

HTML5 Semantic CSS Variables & Grid Vanilla Modern JS Web Audio API SVG Animations LocalStorage Engine

100% Privacy & Offline Ready

Everything you create stays right in your browser's Local Storage. Export full JSON backups anytime or restore them easily in Settings.
