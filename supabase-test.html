💡 How to Configure Supabase Locally:

  1. Create a project in your Supabase Dashboard.
  2. Execute supabase/migrations/0001_initial_schema.sql in your project's SQL Editor.
  3. Copy your Project URL and anon / public key into js/supabase-config.local.js: 
    window.STUDYFLOW_SUPABASE_CONFIG = {
  url: "https://your-project.supabase.co",
  publishableKey: "your-anon-or-publishable-key"
};
  4. Security Rule: NEVER paste service_role or secret keys into browser configuration!
